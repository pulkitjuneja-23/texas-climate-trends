# Photograph credits and licences

Every image in this folder is **public domain** — a work of the United States
federal government, which carries no copyright. None requires a licence fee,
attribution, or permission, and none becomes a problem if this repository goes
public or the site is ever monetised.

Credit is given anyway. It costs nothing and it is the same rule the rest of the
project follows: say where a thing came from.

Sources were checked individually against Wikimedia Commons' machine-readable
licence metadata rather than trusting a stock site's blanket claim. Stock
libraries that permit free commercial use (Unsplash, Pexels) were considered and
passed over: they carry no indemnification and no model releases, and a
government work has neither problem.

## Why these three

The hero and the irrigated shot were **taken in Texas**, which matters for a
Texas tool — a generic stock field would have been easier to find and would have
said nothing true about the place.

The drought photograph is from Arkansas, not Texas. It was chosen because no
comparably good public-domain Texas drought image was found, and the subject —
a burnt-off corn crop — reads correctly regardless of the state line. If it is
ever replaced with a Texas equivalent, that is an improvement, not a fix.

## If you replace one

Keep to public-domain government imagery (USDA ARS, USDA NRCS, NASA) or verify
the licence yourself on Wikimedia Commons. Re-encode to roughly the display size
before committing: the hero was 5464 x 3640 and 1.4 MB as downloaded, and is
1800 x 620 and 352 KB here. Aerial crop rows are high-frequency detail that JPEG
compresses badly, so check the file size rather than assuming.
